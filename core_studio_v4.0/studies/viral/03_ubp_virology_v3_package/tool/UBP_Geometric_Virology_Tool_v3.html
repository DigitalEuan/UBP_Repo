What is UBP Geometric Virology? This tool applies the Universal Binary Principle (UBP) to structural virology. Each protein is mapped to a 24-bit Golay codeword using its physicochemical properties (molecular weight, isoelectric point, GRAVY index, secondary structure). The resulting vectors are analyzed using the Leech Lattice (Λ₂₄) to compute Symmetry Tax (geometric stability), Tilt Angle (evolutionary orientation), and TGIC Relational Gravity (binding energy). All computations use exact integer fractions — no floating-point arithmetic.

ℹ️ About the Universal Binary Principle (UBP)

The Universal Binary Principle (UBP) is a theoretical framework proposing that all physical reality can be represented as patterns of binary information within a 24-dimensional geometric structure — specifically, the Leech Lattice (Λ₂₄) and its associated error-correcting code, the extended binary Golay code G₂₄.


Key Principles:

  • Float-Free Mathematics: All computations use exact integer fractions (Python's Fraction class), eliminating floating-point errors.
  • Golay Encoding: The [24,12,8] extended binary Golay code provides 4,096 valid codewords with minimum Hamming distance 8, enabling error correction of up to 3 bit errors.
  • Leech Lattice Metrics: The Symmetry Tax measures geometric stability; the Tilt Angle measures orientation relative to Universal North.
  • TGIC Relational Gravity: Multi-node energy calculations model the "gravitational" attraction between geometrically similar entities.

In Virology: Protein physicochemical properties are mapped to math_dna strings, which are deterministically hashed to 24-bit Golay vectors. The resulting geometric signatures can predict viral fitness, antibody affinity, and therapeutic efficacy without requiring molecular dynamics simulations.
