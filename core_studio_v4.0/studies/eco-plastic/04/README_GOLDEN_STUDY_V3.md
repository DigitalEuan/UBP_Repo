#### Step 4: 3D Shape Descriptor Integration

For each compound, we calculated approximate 3D geometric descriptors:

1. **Principal Moments of Inertia (PMI)**:
   - PMI₁, PMI₂, PMI₃ (ordered: I_x ≥ I_y ≥ I_z)
   - Estimated from molecular weight and structural class
   - PMI Ratio = PMI₁/PMI₃ (elongation measure)
   - Range: 1.03 - 3.77

2. **Radius of Gyration (Rg)**:
   - Measure of molecular size
   - Scales as MW^(1/3) for globular molecules
   - Adjusted for linear/branched structures
   - Range: 5.97 - 28.21 Å

3. **Spherocity (Ψ)**:
   - Shape descriptor: 0 = linear, 1 = spherical
   - Based on ring count and rotatable bonds
   - Range: 0.19 - 0.86

4. **Asphericity (κ²)**:
   - Deviation from spherical symmetry
   - Complement of spherocity
   - Range: 0.14 - 0.81

**3D Descriptors Enable**:
- Testing if "geometric tension" in UBP space correlates with physical 3D geometry
- Validation that informational substrate properties map to real molecular shapes
