## Getting Started

### Installation
1.  **Download the latest version from:** [https://github.com/DigitalEuan/UBP_Repo/tree/main/core_studio_v4.0/versions]
2.  **Install dependencies:** npm install
3.  **Set your API Key in:** .env.
4.  **Run the studio:** npm run dev

### Usage Flow
1.  **Initialize:** Wait for the [SYSTEM] READY signal in the console.
2.  **Workspace files automatically download from:** [https://github.com/DigitalEuan/UBP_Repo/tree/main/core_studio_v4.0/core]
3.  **Define:** Discuss your phenomenon with the AI Assistant who will generate the initial Python script, or create/upload your own.
4.  **Run Study:** Click RUN to execute the Python kernel.
5.  **Visualize:** Toggle the Visual Insights pane to view the 3D manifold generated by save_scene_3d.
6.  **Promote:** If new Laws are discovered and properly tested, the user updates the System Knowledge Base by copying output from the `HEX_DB.store_law(...)` into the system_kb and ubp_hash_memory_kb files.
