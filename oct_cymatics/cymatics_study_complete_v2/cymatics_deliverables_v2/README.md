# Cymatics in the Bitfield - Comprehensive Study Deliverables

This package contains the complete, expanded study on Cymatics in the Bitfield, reflecting the revolutionary nature of the Universal Binary Principle (UBP).

## Contents

- `paper_v2.tex`: The comprehensive LaTeX source file.
- `paper_v2.pdf`: The compiled 7-page scientific paper.
- `figures/`: Contains the visualization from the 256x256 study.
- `data/`: Contains the generated data, including the first UBP-FOCC and the 256-study results.
- `code/`: Contains the original Jupyter notebook.
- `docs/`: Contains the extracted markdown cells from the notebook and the UBP instruction manual.
