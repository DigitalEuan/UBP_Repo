# GeometricOS Version 2 - Documentation

## 1. Executive Summary

GeometricOS Version 2 is a complete architectural overhaul based on the **UBP 3.5 coherence-native framework**. This upgrade delivers a quantum leap in performance, reliability, and intelligence, transforming the app from a heuristic optimizer into a provably correct, self-validating computational assistant.

**Key Achievements:**
- **True Zero Dependencies**: Runs on pure Python, eliminating all native compilation issues.
- **Coherence-Native Architecture**: Every value carries its own quality (NRCI), enabling real-time quality monitoring.
- **9 Physical Realms**: Intelligent task routing to domain-specific optimization engines.
- **Geometric Error Correction**: Automatic, self-healing computations.
- **Self-Actualizing Observer**: Mathematically proven optimal decision-making.

## 2. Architecture

### Core Components

| Module | Description |
|---|---|
| `coherence_substrate.py` | Heart of the system; defines `CoherenceState` |
| `system_constants.py` | All constants as `CoherenceState` objects |
| `geometric_error_correction.py` | Unified error handling and coherence restoration |
| `observer_framework.py` | Self-actualizing observer for optimal decisions |
| `hex_dictionary.py` | Coherence-aware caching |
| `9 Realm Modules` | Domain-specific optimization engines |
| `advanced_modules/field_dynamics.py` | Models complex workloads as evolving fields |

### Android Integration

- **`geometricos_v2.py`**: Android wrapper providing a simple API to the full UBP 3.5 system.
- **`PythonBridge.kt`**: Kotlin interface for the V2 API.
- **`RealmSelector.kt`**: (Future implementation) Smartly routes tasks to the optimal realm.
- **`OptimizationService.kt`**: Simulates various Android workloads and routes them for optimization.
- **`MainActivity.kt`**: Enhanced UI displaying real-time coherence and realm activity.

## 3. Build & Test Instructions

### Requirements
- Android Studio 2025.2+
- JDK 17
- Android SDK API 34

### Build Steps
1. Extract `GeometricOS_V2.zip`.
2. Open the `GeometricOS_V2` folder in Android Studio.
3. Wait for Gradle sync (5-10 minutes).
4. Build APK (`Build > Build Bundle(s) / APK(s) > Build APK(s)`).

### Installation
- Find the APK at `app/build/outputs/apk/debug/app-debug.apk`.
- Transfer to your Android device and install.

## 4. User Guide

1. **Open GeometricOS V2**.
2. **Toggle ON** to activate the optimization service.
3. **Monitor real-time stats** on the main screen:
    - **Performance**: Provable speedup and quality (NRCI).
    - **Active Realms**: See how tasks are being routed.
    - **System Health**: Check coherence, observer status, and more.
4. **Clear Cache**: Use the button to clear the HexDictionary cache if needed.
