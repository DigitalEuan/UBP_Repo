# UBP_Repo

Welcome to **UBP_Repo** – an open collection of research papers, documentation, and computational notebooks related to UBP.

## Repository Purpose

This repository is an ongoing effort to document and explore the UBP project through written papers and executable notebooks. It serves as both a knowledge base and an interactive environment for analysis, experiments, and sharing insights about UBP.

## Contents

- **Jupyter Notebooks (`*.ipynb`)**  
  The main content of this repo consists of Jupyter notebooks, which provide interactive documentation, code demonstrations, and analysis related to UBP.  
  *Language composition: ~97% Jupyter Notebook.*

- **Python Scripts (`*.py`)**  
  Supporting scripts and utilities in Python for data processing, analysis, or supplemental functions used within the notebooks.  
  *Language composition: ~3% Python.*

## Getting Started

1. **Clone the repository:**
   ```sh
   git clone https://github.com/DigitalEuan/UBP_Repo.git
   cd UBP_Repo
   ```

2. **Open the notebooks:**  
   You can explore and run the notebooks using [JupyterLab](https://jupyter.org/) or [VS Code](https://code.visualstudio.com/).

   ```sh
   jupyter lab
   # or
   jupyter notebook
   ```

3. **Install dependencies:**  
   If any notebooks require specific Python packages, see individual notebook cells or look for a `requirements.txt` if present.
