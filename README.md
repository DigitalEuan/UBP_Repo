## What Is UBP?

The **Universal Binary Principle (UBP)** models reality as a deterministic, toggle-based computational substrate — a multidimensional Bitfield governed by geometry, resonance, and error correction. It is not a speculative framework. Large portions of the system are **implemented, runnable**.

UBP is based on real mathematical structures:

| Structure | Role in UBP |
|---|---|
| **Extended Binary Golay Code** G₂₄ [24,12,8] | Error correction substrate; foundation of the OffBit unit |
| **Leech Lattice** Λ₂₄ | 24-dimensional geometry governing toggle interactions |
| **Monster Group** | Symmetry ceiling of the UBP system |

### Core Concepts

- **TGIC** — *Triad Graph Interaction Constraint*: Three-axis, Six-face, Nine-interaction geometry that constrains computation into a spatial inquiry rather than arithmetic
- **NRCI** — *Non-Random Coherence Index*: The primary metric of system coherence, routinely exceeding 99.9999% via GLR error correction
- **GLR** — *Golay-Leech-Resonance*: The error correction mechanism derived from the Golay code and Leech lattice geometry
- **OffBit** — The 24-bit fundamental unit of UBP information, stacked into four layers representing dimensions of reality
- **Observer Constant Y** — A single rational constant defined via a 50-term continued-fraction approximation of π, from which fundamental physical constants are derived
- **E/C/M Triad** — Existence, Speed of Light (c), and Pi (π) as the three irreducible primitives of the system
- **PI, PHI and Euler's 'e'** provide all required mathematical constants, all other values are derived
- UBP uses **eml** for sovereign calculation (no reliance on numpy or sympy)
- noisecore is an automatic calculations machine that uses geometric tension for arithmetic and I have never seen it fail a test yet, running 10000 batches of random tests

### Philosophy

It is an **open research and development archive** — a working record of an independent investigation into whether reality can be modelled from a single coherent computational principle. The code is empirical: every script exists to verify whether a specific UBP concept holds up against real-world data.

## Running the Code

The UBP codebase is **pure Python with zero external dependencies**. Any of the following environments work:

- **UBP Core Studio APP** — my recommendation for using the UBP. specifically designed to work with the UBP system: a pyodide environment to run script studies using the UBP python scripts which automatically download the latest versions from the main GitHub repository, an ai assistant us wired through the app to receive system_kb memories (also automatically download) and has semantic and geometric reasoning to assist with retrieval of relevant memories, a visualing Three.js tab allows 3D data examination, a Frame of Mind (FOM) module attempts to help weight memory retrieval
- **Local terminal** — highest control; clone or copy individual study folders
- **Google Colab** — recommended for new users; AI assistance available for extending scripts
- **Kaggle Notebooks** — good alternative with free GPU access

Individual study folders are designed to be self-contained. You do not need to clone the entire repository to work with a specific module.
