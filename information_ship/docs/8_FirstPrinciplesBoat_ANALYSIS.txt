### Notebook Analysis and Summary

This notebook, titled "The First Principles Boat," is a demonstration of exact rational arithmetic for physical and abstract computations, aiming to avoid floating-point approximations. It is designed to perform calculations using `fractions.Fraction` for high precision.

**Key Features and Philosophy:**

1.  **Exact Rational Arithmetic:** The core principle is to use `fractions.Fraction` for all internal calculations, ensuring no precision loss due to floating-point numbers. This allows for indefinitely extendable precision, limited only by hardware and memory.
2.  **Golay-Aligned Precision Display:** The output prioritizes a 24-bit aligned display (~7 decimal digits), nodding to the Golay G24 code, which is presented as a "sweet spot" for practical readability. It also demonstrates the ability to extend precision beyond this for verification.
3.  **Self-Contained:** The code has no external dependencies beyond Python's standard library (`fractions`, `re`, `sys`, `math`).
4.  **Parsing Scientific Notation:** A custom `parse_fraction` function handles scientific notation strings (e.g., "1.23e-4") and converts them into exact `Fraction` objects without intermediate float conversion.

**Functionality Demonstrated:**

*   **Gravitational Force Calculation:** The `compute_gravity` function calculates gravitational force (F = G * m1 * m2 / r²) using exact rational values for G, masses, and distance. It then displays intermediate and final results with both Golay-aligned and extended precision, as well as the exact rational form.
*   **Interactive Command Line Interface:** The initial `main` function provides an interactive "boat>" prompt where users can input commands like `gravity <m1> <m2> <r>` or `help`.

**SEA-WORTHY UPGRADES (`SEA-WORTHY UPGRADES: First Principles Only` cell):**

The second part of the notebook introduces significant enhancements:

1.  **Dimensional Awareness:** A `FirstPrinciplesQuantity` class is implemented to track physical dimensions (Mass, Length, Time) alongside the exact rational value. This allows for dimensional consistency checks during calculations.
2.  **Dimensional Analysis in Gravity:** The `compute_gravity_with_dimensions` function re-implements the gravitational force calculation using the `FirstPrinciplesQuantity` class, explicitly showing how dimensions combine and verify against expected units.
3.  **Information-Theoretical Tests (`information_sea_trial`):** This section demonstrates the flexibility of the exact computation engine by applying it to abstract, non-physical values (e.g., Planck scale, Avogadro's number, or simple integers like 1, 24, 12, 8). It calculates "information bits" in the rational representation, highlighting the exactness.
4.  **Extreme Scale Resilience Test (`extreme_scale_trial`):** This test aims to push the calculator to its limits, from quantum foam to cosmological scales, assessing its ability to handle extremely large or small numbers while maintaining exact rational representation. It measures the size of the numerator and denominator to indicate complexity.

**Summary:**

This notebook effectively showcases a robust, exact-computation framework built on `fractions.Fraction`. It successfully demonstrates how to maintain numerical precision, incorporate dimensional analysis, and handle a vast range of scales, from abstract information units to physical constants across quantum and cosmological magnitudes, all while adhering to its "first principles" philosophy.
