## How to Use in Overleaf

### Option 1: Upload to Overleaf
1. Go to [Overleaf](https://www.overleaf.com/)
2. Create a new blank project
3. Upload all files from this directory:
   - `dissident_horizon_paper.tex`
   - All four PNG figure files
4. Set `dissident_horizon_paper.tex` as the main document
5. Compile with pdfLaTeX

### Option 2: Local LaTeX Compilation
If you prefer to compile locally:
```bash
pdflatex dissident_horizon_paper.tex
pdflatex dissident_horizon_paper.tex  # Run twice for references
```
